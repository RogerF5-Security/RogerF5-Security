# Changelog

All notable changes to the Roger F5 GitHub profile are documented here.

This project follows [Semantic Versioning](https://semver.org/). The `1.x` entries were reconstructed from the repository history because those milestones were not originally published as Git tags.

## [2.0.0] - 2026-09-09

### Added

- Scan Titan as a featured Chrome extension, with a direct link to its official Chrome Web Store listing.
- A visible profile version badge and this changelog.
- A global community statement welcoming builders, learners and security professionals.

### Changed

- Repositioned the profile around open-source knowledge, practical security tooling and collaboration without borders.
- Expanded the featured product area to represent both RF5 RECON and Scan Titan.
- Adopted Semantic Versioning for future profile releases.

### Removed

- Event-specific references and legacy campaign branding that no longer represented the project direction.

### Why a major release?

Version 2.0.0 marks a public identity and product-portfolio change rather than a routine content edit: the profile now presents a global community mission, features multiple security products and establishes a formal release history.

## [1.2.0] - 2026-06-18

### Changed

- Reworked the profile into the current terminal-inspired presentation.
- Clarified the professional mission, specialties and authorized-security focus.
- Improved accessibility with alternative text for badges and media.
- Added Credly and expanded the dedicated hardware section.

## [1.1.0] - 2026-05-20

### Added

- WiFi Pineapple, Chameleon Ultra and Ubertooth One to the hardware portfolio.

## [1.0.0] - 2026-01-29

### Added
