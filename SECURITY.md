# Política de seguridad

Para comunicar una posible vulnerabilidad de este repositorio, utiliza **Security → Report a vulnerability**:

https://github.com/RogerF5-Security/RogerF5-Security/security/advisories/new

Incluye el componente y la revisión afectados, pasos de reproducción, evidencia e impacto esperado. Evita adjuntar credenciales, datos personales o información interna de clientes y empresas.

Si el problema afecta a otra herramienta de Roger F5, utiliza el canal privado del repositorio correspondiente. Las incidencias de presentación y los enlaces rotos pueden comunicarse mediante un issue público.

La rama principal representa la versión mantenida de este perfil.
